# openpi · RoboKata Training

OpenPI 原生训练循环：分段 Demo π0 支持 RoboTwin43 和 IG C15；原生 text π0.5 支持 RoboTwin43。两类模型不是同一架构。

从主分支克隆完整集合并按 `docs/TRAINING.md` 操作：

```bash
git clone https://github.com/xieshanrui/RoboKata-Training.git
cd RoboKata-Training
git submodule update --init
```
